01 RESEARCH

Helping students tell real academic opportunities from fake ones.

A supervised research project on academic impersonation fraudulent offers, using machine learning to help students assess scholarship, internship and journal offers aimed at university students.

AT A GLANCE

THE PROBLEM

Why it matters.

Students apply for scholarships, internships and journals constantly, and attackers impersonate legitimate institutions to exploit that. A student who cannot tell a genuine offer from a fake one can lose money, personal data or time.

As an effort to address this gap, this research includes a unified cybersecurity based framework under one singular web tool that can be utilized by students.

Method

How I did it.

  1. Defined the problem and the types of offer to cover: scholarships, internships and journals.
  2. Planned the study with my supervisor.
  3. Collected data from various online sources like university websites, popular scholarship sites, job listings, scam listings, journal indexes and more.
  4. Turned offer text into features with TF-IDF vectorization.
  5. Trained three text-classification machine learning models in Python with scikit-learn.
  6. Built a web interface so students can assess an offer themselves.

Results

What I found.

Dataset
1,240 samples: 620 fraudulent, 620 genuine (840 scholarship/internship: 420/420; 400 journal: 200 predatory/200 legitimate)
Best model (scholarship + internship)
Random Forest (highest accuracy); Naive Bayes has the highest precision
Accuracy (scholarship + internship)
97.38% (RF) / 97.02% (NB)
Precision / recall (scholarship + internship)
98.38% / 96.43% (RF); 99.76% / 94.29% (NB)
Best model (journal)
Logistic Regression (title + DOAJ + Scopus flags)
Accuracy (journal, title + flags)
98.75% ±1.25 (LR) / 98.00% ±1.87 (RF) / 96.25% ±2.80 (NB), 10-fold CV
Precision / recall (journal)
97.62% / 100.00% (LR); 96.69% / 99.50% (RF); 97.45% / 95.00% (NB)
Main finding
RF and NB outperform the Logistic Regression baseline on scholarship/internship posts (93.33%). Text length is the strongest signal: legitimate posts average about 1,121 characters versus about 177 for fraudulent ones. For journals, DOAJ and Scopus indexing drive classification.
One thing about fraud offers
Fraudulent offers are usually short, vague posts: fake listings average about 177 characters while legitimate ones average about 1,121, so length alone separates most of them.

LIMITS

What it can’t do yet.

The study is still in progress, and a text classifier only reflects the data it was trained on. The dataset has 1,240 labelled samples, which is small for a problem where scam styles change quickly. Ablation studies confirmed which features drive the models, but all results come from cross-validation on my own data rather than new, unseen posts.

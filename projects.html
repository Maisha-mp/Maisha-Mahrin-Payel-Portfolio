Research · Machine Learning

Academic Fraud Detection

In progress

Python · Scikit-learn · TF-IDF

Research write-up ↗ Live demo ↗

Overview

An independent research project investigating fraudulent scholarship, internship and academic publication offers that target university students. The work explores how machine learning can support the assessment of suspicious academic opportunities through text classification and structured risk analysis.

My contribution

Defined the research problem, planned the study, collected data from online sources and explored machine-learning approaches for classifying potentially fraudulent offers. I am also developing a web-based interface to make the assessment process more accessible to students.

What I'm exploring

Text preprocessing, TF-IDF feature extraction, classification models, dataset quality and the practical challenges of translating research into a usable tool.

Software Engineering

FlagShip — Feature Flag System

In development

Java · Feature Flags · Evaluation Engine

GitHub ↗

Overview

A software engineering project focused on building a feature-flag platform that allows applications to control feature availability through configurable rules and percentage-based rollouts. The project includes a standalone Java evaluation engine designed around predictable and consistent flag evaluation.

My contribution

Working on the evaluation-engine-first development plan, including flag models, ordered rule evaluation, operators, logical conditions and deterministic, hash-based percentage rollouts.

What I'm learning

Designing reusable software components, implementing deterministic evaluation logic and measuring performance against explicit engineering requirements.

Software · Computer Graphics

Apartment — 2D Interior Scene

Group project

OpenGL · DDA · Bresenham · Midpoint Circle

GitHub ↗

Overview

A group computer graphics project that creates a two-dimensional apartment interior scene using OpenGL. The project applies fundamental rasterization algorithms to construct the visual elements of an indoor environment.

My contribution

Designed the scene layout and implemented the DDA line algorithm, Bresenham's line algorithm and midpoint-circle algorithm.

What I learned

Understanding how fundamental graphics algorithms generate pixels, translating geometric concepts into drawing operations and coordinating visual components within a group project.
